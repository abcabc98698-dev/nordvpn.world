## 📖 项目简介

本项目为 **NordVPN（[nordvpn.world](https://nordvpn.world)）** 品牌方获得官方授权的独立品牌官网落地页、注册转化中心与技术知识库源码。

项目采用现代前端架构 **Astro 6 + Tailwind CSS 4** 纯静态站点生成（SSG），深度集成搜索引擎友好架构（SEO）、标准 Schema 结构化数据、暗黑模式切换、一键复制邀请码与全端高颜值响应式设计，专为企业级海外专线网络、跨境出海直播、AI 研发及超清流媒体加速打造。

## ✨ 核心特性与架构亮点

### 🚀 企业专线与前沿协议
- **物理内网专线**：采用企业级 **IEPL / IPLC** 跨境光纤内网骨干传输，不过公网国际出口，晚高峰 0 拥堵、0 丢包。
- **VLESS 协议架构**：新一代轻量抗干扰架构，剔除握手冗余开销，具备极强的网络抗封锁与长时在线稳定性。
- **极速大带宽**：全节点单节点峰值最高 **2.5Gbps**，全网一律 **×1 真实倍率**，拒绝虚假计费。
- **全平台多端适配**：提供官方自研 Windows / macOS / Android / iOS 客户端；同时完美支持 **Clash、Shadowrocket、Sing-box、Surge、v2rayN** 等通用客户端订阅一键导入。
- **不限在线设备**：打破传统设备连接数限制，无论是个人全套数码终端还是出海团队协同办公，多端同时在线无门槛。

### 🤖 业务场景全方位解锁
- **AI 生产力集群**：针对 OpenAI (ChatGPT)、Claude 3.5 Sonnet、Midjourney、Google Gemini 等 AI 生产力平台持续路由调优，告别风控拦截。
- **TikTok 全球短视频与直播**：高纯净原生独享 IP 与超大上行保障带宽，满足跨境电商矩阵多店铺防关联推流需求。
- **4K / 8K 超清流媒体**：全节点解锁 Netflix（全区原生）、Disney+、YouTube Premium、HBO Max 等海外主流流媒体。

### 🔍 工业级搜索引擎 SEO 基础设施
- **静态秒开（SSG）**：预渲染纯静态 HTML，TTFB < 50ms，Lighthouse 性能表现极佳。
- **多引擎无缝抓取**：针对 Googlebot、bingbot、Baiduspider、yisouspider（神马/UC/夸克）定制放行规则与静态直出验证标签。
- **Schema 结构化数据**：全站自动挂载 `WebSite`、`Organization`、`FAQPage`（真实问答富摘要）、`TechArticle` 及 `BreadcrumbList` 面包屑。
- **Canonical 与 URL 规范**：全站 100% 语义化纯小写英文 URL，统一尾部斜杠（Trailing Slash），杜绝重复内容权重分散。
- **商业链接防流失保护**：全站外部推广及控制台注册链接统一施加 `rel="nofollow sponsored noopener noreferrer"` 标记，最大化留存主站权重。

## 🚀 快速上手与本地开发

### 环境要求
- **Node.js**: `>= 22.12.0`
- **包管理器**: `pnpm` (`>= 9.0.0`)

### 1. 克隆代码仓库
```bash
git clone https://github.com/abcabc98698-dev/nordvpn.world.git
cd nordvpn.world
```

### 2. 安装项目依赖
```bash
pnpm install
```

### 3. 配置环境变量 (可选)
复制环境变量模板文件：
```bash
cp .env.example .env
```
根据需求配置 `.env` 中的核心参数：
```ini
# 正式域名
PUBLIC_SITE_URL=https://nordvpn.world

# 官方注册邀请码与跳转目标
PUBLIC_INVITE_CODE=keqgvT5Y
PUBLIC_REGISTER_URL=https://sahude.gsyvipaff.com/?code=keqgvT5Y#/?code=keqgvT5Y

# 搜索引擎站长平台所有权验证 (可选)
PUBLIC_GOOGLE_SITE_VERIFICATION=
PUBLIC_BING_SITE_VERIFICATION=
PUBLIC_SHENMA_SITE_VERIFICATION=
PUBLIC_BAIDU_SITE_VERIFICATION=
```

### 4. 启动本地开发服务
```bash
pnpm dev
```
打开浏览器访问：`http://localhost:5200`

### 5. 静态打包构建
```bash
pnpm build
```
打包输出目录位于 `./dist`，包含 21 个已完整预渲染并优化的静态 HTML/CSS 资产及 XML Sitemap。

### 6. 本地预览生产构建产物
```bash
pnpm preview
```

## 🌐 生产部署指南

### 方案 A：Cloudflare Pages 部署 (推荐)
1. 登录 Cloudflare 控制台，进入 **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**；
2. 选择本仓库 `nordvpn.world`；
3. 构建配置参数：
   - **Framework preset**: `Astro`
   - **Build command**: `pnpm build`
   - **Build output directory**: `dist`
   - **Node.js Version**: 设置环境变量 `NODE_VERSION=22`
4. 点击 **Save and Deploy**，绑定自定义域名 `nordvpn.world` 即可完成全球 Anycast CDN 分发。

### 方案 B：Vercel 部署
1. 访问 Vercel 控制台，导入 GitHub 仓库 `abcabc98698-dev/nordvpn.world`；
2. Vercel 将自动识别 Astro 框架预设；
3. 点击 **Deploy**，部署完成后在 Settings -> Domains 中绑定 `nordvpn.world`。
