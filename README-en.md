## 📖 Overview

This repository contains the complete source code for **NordVPN ([nordvpn.world](https://nordvpn.world))**, an officially authorized enterprise-grade overseas network acceleration and dedicated line brand landing page, customer registration center, and technical knowledge base.

Built with **Astro 6 + Tailwind CSS 4** static site generation (SSG), this project delivers exceptional Lighthouse performance scores, full search engine crawler compatibility (Google, Bing, Baidu, Shenma), rich Schema markup, dark mode switching, and an elegant responsive experience across all screen sizes.

## 🚀 Quick Start

### Prerequisites
- **Node.js**: `>= 22.12.0`
- **Package Manager**: `pnpm` (`>= 9.0.0`)

```bash
# 1. Clone repository
git clone https://github.com/abcabc98698-dev/nordvpn.world.git
cd nordvpn.world

# 2. Install dependencies
pnpm install

# 3. Start local development server
pnpm dev

# 4. Build for production (SSG static output)
pnpm build

# 5. Preview production build locally
pnpm preview
```

## 🌐 Production Deployment

- **Cloudflare Pages**: Connect your GitHub repository `abcabc98698-dev/nordvpn.world`, select Astro preset, build command `pnpm build`, output directory `dist`.
